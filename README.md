# Stjärnracet

Ett racingspel för barn. Kör bilen, hoppa över hinder och samla stjärnor.

Spelet är en statisk webbapp och går att spela direkt i webbläsaren, även i Safari på iPhone:

https://9w9wt9yj98-cpu.github.io/Stjarnracet/

En separat 3D-prototyp ligger under `3d/` (egen sida, eget sparande). Det vanliga spelet ovan är oförändrat.

Lägg gärna till sidan på hemskärmen så startar den som en app.
